# 제품 개요

## 목적

Betting Analysis System은 K1·J1 실제 경기 정보와 공개 배당을 조회하고, Betman 마감 배당·경기 결과 및 사용자의 판단 기록을 보존하는 개인용 분석 도구입니다. 결과를 보장하거나 자동 베팅을 수행하지 않습니다.

## 사용자 흐름

1. 앱은 한국시간 오늘부터 14일 뒤까지 K1와 J1 일정을 불러오고, 처음에는 예정 경기 목록만 전체 폭으로 표시합니다. 첫 경기를 자동 선택하지 않습니다.
2. 사용자는 경기 목록에서 한 경기를 명시적으로 선택해 상세 분석을 열고 팀 기록, 맞대결, 리그별 공식 순위를 확인합니다.
3. 상세 분석은 외부 공급자가 제공하는 참고정보인 API-Football Predictions와 선택 경기의 API-Football pre-match odds를 표시합니다. 닫기(`×`, `상세분석 닫기`)를 누르면 목록 상태로 돌아갑니다.
4. Betman 회차 URL이 설정돼 있으면 확인된 팀 별칭과 일정으로 해당 경기의 Betman 시장을 연결합니다.
5. 사용자는 Betman 시장의 선택지에 확률을 입력하고, 합계가 1인 경우에만 저장합니다. 입력한 확률은 사용자의 판단 기록이며 추천이 아닙니다.
6. 저장된경기 메뉴에서 각 행의 선택지 하나를 표시용으로 선택하고, 변경된 여러 행을 `선택 저장`으로 한 번에 저장합니다. 선택지 음영 표시는 사용자의 판단 기록이며 추천이 아닙니다.
7. 배당기록 메뉴는 D1에 이미 저장된 기록을 먼저 표시하고, 익명 Betman `G101` 마감게임 동기화가 끝나면 다시 조회합니다.

## 화면 규칙

- 순위 메뉴는 K리그1/J리그1 탭으로 분리됩니다.
- 리그와 순위 화면은 K1/J1의 서로 다른 API 시즌 키를 각각 표시합니다.
- 리그 하나가 공급자 오류여도 다른 리그가 성공하면 해당 리그 데이터는 계속 표시하고, 경기 목록 위에 접근 가능한 부분 실패 경고를 표시합니다. 이 경고는 “예정 경기 없음”과 구분됩니다.
- 상세를 연 넓은 화면에서는 경기 목록과 상세 분석이 좌우로 나란히 표시되며, 두 영역은 각각 독립적으로 스크롤됩니다. 1050px 이하에서는 상세 분석이 목록을 대체하고 닫기 버튼으로 목록에 복귀합니다.
- Predictions와 사전 배당은 경기 선택 후에만 요청합니다. 선택이 없으면 두 API를 호출하지 않습니다.
- 최근 맞대결은 각 경기의 실제 승리팀 이름만 녹색 굵게 표시하고, 무승부에서는 어느 팀도 강조하지 않습니다.
- 사전 배당은 bookmaker 선택상자 없이 API 응답의 모든 bookmaker를 응답 순서대로 한 표에 표시합니다. 각 bookmaker는 Match Winner만 `Home / Draw / Away`의 고정 순서와 소수 둘째 자리로 표시하며, 세 값 중 하나라도 없으면 해당 행은 `미제공`입니다. bookmaker가 없으면 오류가 아닌 “제공된 사전 배당 없음” 상태를 표시합니다.
- Betman 매칭은 리그, 날짜, 시작시간 15분 이내, 양 팀의 확인된 팀 ID가 모두 일치할 때만 허용합니다.
- 저장된경기 선택 표시는 한 행당 하나만 허용합니다. 선택된 항목을 다시 누르면 해제되고, 선택된 셀은 주황색으로 표시됩니다. 확률·배당·기대수익과 저장일시는 변경하지 않으며 미저장 변경이 있으면 조회·메뉴 이동·페이지 종료 전에 경고합니다.
- 배당기록은 K1/J1의 게임유형 `일반`, 종목/마켓 `축구 승무패`, 사전조건 `-`인 정상 완료 경기만 최신순으로 페이지당 30개 표시합니다. 표준 팀명과 Betman 원문 팀명을 함께 제공하고, 취소·미정·배당누락·팀매칭실패는 표가 아닌 네 개의 제외 건수로 안내합니다.
- `PENDING` 회차는 마지막 성공 시각과 마지막 시도 시각 중 더 최근 값에서 30분이 지나야 다시 조회합니다. `FINAL` 회차와 이미 확정된 경기 결과·최종 배당·원문 팀명은 이후 원천 오류나 빈 응답으로 변경하거나 삭제하지 않습니다.

## 비목표

- 자체 승부예측 모델, 자동 추천 또는 자동 확률 산출
- 모델 학습, 확률 보정 또는 백테스트
- PWA 오프라인 기능
- 자동 베팅, 베팅 권유, 수익 보장
- 알 수 없는 팀 표기의 추정 매칭
- 발매 중 배당의 변동 시계열 또는 로그인·구매가 필요한 Betman 데이터
