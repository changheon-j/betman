## 제약

2026-27 J1은 API `season=2027`이며 `coverage.odds=true`입니다. coverage와 무관하게 개별 경기 배당은 비어 있을 수 있으므로 정상 빈 응답 처리는 유지합니다. 별칭 확대는 확인된 팀 ID와 실제 표기만으로 진행하고, 정규화된 별칭이 다른 팀 ID와 충돌하면 초기화를 실패시킵니다.
