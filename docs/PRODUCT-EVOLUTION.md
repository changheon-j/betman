# 제품 변화 기록

## 출발점

최초 저장소는 Vinext 전체 스택 starter였고, 첫 제품 화면은 정적 K리그1 샘플 일정·순위·관심 경기와 데모 상세정보를 표시하는 경기 안내 화면이었다.

## 현재까지의 변화

1. K리그1 샘플을 API-Football 실제 일정·순위로 교체했다.
2. J리그1과 리그별 시즌 규칙을 추가했다.
3. 명시적 경기 선택 기반 상세 분석, 최근 경기, 맞대결을 추가했다.
4. API-Football Predictions와 사전 배당을 외부 참고정보로 추가했다.
5. Betman 현재 회차 배당의 보수적 경기 연결을 추가했다.
6. Betman 마감 경기 결과·최종 배당의 D1 아카이브를 추가했다.
7. 사용자 확률·기대수익과 단일 선택 표시의 D1 기록을 추가했다.

제품의 중심은 샘플과 관심 경기 탐색에서 실제 배당·결과와 사용자 판단 기록으로 이동했다. 현재는 실제 정보를 확인하고 나중에 자신의 판단을 되돌아볼 수 있는 개인용 도구에 집중한다.

## 현재 제품 기준선

현재 제품은 K1·J1 실제 경기 정보와 공개 배당을 조회하고, Betman 마감 배당·경기 결과 및 사용자의 판단 기록을 보존하는 개인용 분석 도구다.

배포 안정성, 접근 제어, 데이터 품질, 운영은 이제 새로운 예측 기능보다 우선한다.

## 폐기한 미래 구상

자체 승부예측 모델, 자동 확률 산출, 모델 학습, 확률 보정 및 백테스트는 제품 범위에서 제외한다. API-Football Predictions는 외부 공급자의 참고정보이므로 유지한다.
